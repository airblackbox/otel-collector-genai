Redaction Engine — 4 Privacy Modes

SHA-256 hashes for correlation. Preview chars for debugging. Denylist for secrets.

drop
Remove entirely
hash
SHA-256 only
hash+preview
Hash + first N chars
truncate
Cut at N chars
[genaisafe:redact] Mode: hash_and_preview (48 chars)
[genaisafe:denylist] Pattern match: sk-[a-z0-9]{20,} → [REDACTED]
[genaisafe:denylist] Pattern match: Bearer .* → [REDACTED]

Simple YAML Config

Drop into your existing collector config — all features are toggleable

otelcol-config.yaml
processors:
genaisafe:
redact:
mode: "hash_and_preview"
preview_chars: 48
keys: ["gen_ai.prompt", "gen_ai.completion"]
denylist_regex:
- "(?i)sk-[a-z0-9]{20,}"
- "(?i)api[_-]?key"
metrics:
enable: true
loop_detection:
enable: true
repeat_threshold: 6
